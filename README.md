## 📋 Опис проєкту

Проєкт є інтерактивним генератором CSS-коду, розробленим на чистому JavaScript (Vanilla JS) без використання сторонніх бібліотек чи фреймворків[cite: 6]. 

Додаток дозволяє в реальному часі налаштовувати зовнішній вигляд елементів за допомогою зручних елементів керування (ползунків `range`, випадаючих списків `select`, полів введення) та одразу отримувати готовий CSS-код для копіювання[cite: 6].

---

## ✨ Реалізований функціонал

### 1. Робота з DOM та подіями (І рівень)
* **Перемикання вкладок:** перемикання між секціями налаштувань (`Border Radius`, `Height`, `Overflow`)[cite: 6].
* **Динамічна генерація стилів:** зчитування значень з елементів керування та миттєве застосування їх до блока попереднього перегляду (`#preview`)[cite: 6].
* **Відображення CSS-коду:** автоматичне формування готового CSS-коду у текстовому полі `textarea`[cite: 6].

### 2. Форми, клавіатура та буфер обміну (ІІ рівень — Варіант №6)
* **Додаткові CSS-властивості:** повна підтримка налаштування висоти (`height`) та режиму переповнення (`overflow`)[cite: 6].
* **Валідація форми пресетів:** обробка подій `focus` та `blur` із додаванням візуальної індикації (`.focused`, `.error`) та повідомлень про помилки[cite: 6].
* **Перехоплення відправки форми:** запобігання перезавантаженню сторінки за допомогою `event.preventDefault()`[cite: 6].
* **Гарячі клавіші:** скидання всіх налаштувань до значень за замовчуванням при натисканні клавіші `Escape`[cite: 6].
* **Копіювання коду:** швидкий запис сформованого CSS-коду в буфер обміну (`navigator.clipboard.writeText`) із сповіщенням користувача[cite: 6].

### 3. Просунута робота з подіями (ІІІ рівень)
* **Делегування подій:** обробка кліків по вкладках через єдиний слухач подій на контейнері `#tabsContainer`[cite: 6].
* **Керування спливанням подій:** застосування `event.stopPropagation()` на кнопці всередині блока попереднього перегляду для запобігання передачі події батьківському елементу[cite: 6].
* **Події миші:** реакція на наведення курсора (`mouseover` / `mouseout`) із зміною зовнішнього вигляду блока[cite: 6].
* **Відстеження координат:** виведення поточних координат курсора (`clientX` / `clientY`) відносно видимої області вікна[cite: 6].
* **Плавне прокручування:** поява кнопки «Наверх» при прокручуванні сторінки нижче 300px (`window.scrollY`) та плавний повернення до початку документа[cite: 6].
